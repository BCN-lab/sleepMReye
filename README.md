# Gaze-dependent brain activity in eyes-closed rest and sleep

The following repo contains scripts, notebooks, and GLM design configs relevant for the 
analysis of our paper. 

The majority of analysis and figure generation is contained in the `notebooks/`.
The main GLM group-level figures are generated by the `mreyemove` pipeline and 
will be saved in `BIDS_ROOT/derivatives/mreyemove/group/func/qc_reports/[<desc_add>-]<config.name>-<config.method>/`

Before running the analysis notebooks, you will need to run
1. The signal extraction pipeline without and without the `--clean` option (see [mreyemove](https://github.com/DeepMReye/MReyeMove) README)
2. The GLM models (for more details also refer to [mreyemove](https://github.com/DeepMReye/MReyeMove))
e.g
```
mreyemove-glm \  
 --config SleepMReye/sleepmreye/designs/original_sleep.yml  \
 --bids-root BIDS_ROOT \
 --task sleep  \
 --tr=2.1 \
 --mrio sleepmreye  \
 --njobs 8 \
 --vmax 8  \
 --desc-add clean \
 --io-kwarg load_eog=False # True for EOG runs ;)
```

The necessary model pipelines to run are (in order of paper figures):

| Expanded Cerebellum       | `designs/original_cer.yml`       | `clean`               | 4                   |
